Дипломный проект / ТЭК
# Инструкция к запуску

После клонирования проекта - необходимо скопировать и заполнить .env по примеру из .env.example в корне проекта.

## Инициализация docker

Далее необходимо выполнить docker compose up -d --build

После этого - необходимо выполнить docker compose exec php composer setup

## Конфигурация Backend(laravel)

Далее в файле backend/laravel/.env заполнить поля для базы данных, телеграмм бота. 

Для полей reverb'a необходимо сгенерировать данные с помощью docker compose exec php php artisan reverb:install

Если не настроете поля reverb'a, то уведомления через вебсокеты работать не будут, чтобы увидеть уведомление о новой заявке - придется перезагружать страницу.

## Работа с базой данных и правами

Для использования уже созданного сидера для заполнения модулей в базу - используйте docker compose exec php php artisan migrate:fresh --seed --seeder=ModuleSeeder

Можете изменить данные в ModuleSeeder на свои, для быстрого заполнения базы данных.

Далее используйте docker compose exec php php artinsan moonshine:user для создания админа в панель администратора.

Если при открытии админ-панели получаете 500 ошибку - необходимо выполнить docker compose exec php chmod -R 777 storage bootstrap/cache

Также используйте docker compose exec php php artisan storage:link для правильной работы изображений.

Если возникают проблемы - попробуйте остановить и поднять контейнеры, docker compose down - docker compose up -d

## Панель Администратора и Роли

Для входа в Админ панель используйте данные, которые вводили в docker compose exec php php artisan moonshine:user

Если данные не помните - рекомендуется с помощбю той же команды создать нового админа, а старого удалить из базы данных.

В Админ панели в вкладке "Роли" - создайте роль Manager

В вкладке "Админка" - создайте пользователя с ролью "Manager", 

Важное примечание - у пользователя с ролью "Admin" не видна часть функционала роли "Manager", Админ предназначен для наблюдения за Менеджерами, а не выполнения работы за них.

Страница открытия панели администратора - http://admin.localhost/

# Тестирование 
При переходе по http://localhost:80 должна отображаться страница лендинга.

При нажатии на кнопки "Оставить заявку/Получить демо" страница должна прокручиваться вниз к форме.

При заполнении формы валидными данными, а именно: Имя должно состоять из латинницы, либо кириллицы, может содержать тире. Номер телефона должен состоять только из цифры, не менее 10 и не более 12. Электронная почта должна состоять только из латинницы, содержать @, также может содержать другие спец.символы. Пример почты - example@mail.com.

При отправке формы с валидными данными появится сообщение об успешной отправке данных и данные отобразятся в чате с телеграм ботом(если был подключен), а также сохранятся в базе данных.

При отправке формы с невалидными данным, поле непрошедшее валидацию будет подсвечено красным и появится надпись указывающая на ошибку.

Для тестирования модулей  необходимо перейти по http://localhost:8081 войти в панель phpMyAdmin при помоще данных, которые были указаны в .env, перейти в базу данных -> таблицу modules и изменить название/текст модуля, при перезагрузке страницы - модуль загрузится с изменениями.

# Устранение проблем:
При изменении клиентской части (frontend'a) необходимо выполнить docker compose up -d --build nginx для пересборки клиентской части и применения изменений.

Для удобной работы с базой данных в контейнере находится phpmyadmin - графический интерфейс с помощью которого можно быстро изменять данные внутри базы данных.

Если загрузка страниц начинает тормозить - попробуйте перезапустить контейнеры.

Если скорость загрузки страниц у вас более 2 секунд и ваша операционная система - Windows, то - вероятнее всего у вас неправильно настроен Docker.
